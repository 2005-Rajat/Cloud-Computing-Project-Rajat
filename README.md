# 🍽️ Jaiveer Di Hatti – Cloud Computing Frontend Project

A modern, responsive, and premium frontend website for **Jaiveer Di Hatti**, a famous local snack shop located in **Civil Lines, Ludhiana**.  
This project was created as part of the **Cloud Computing Subject Project**, where the task was to design and deploy the frontend of a nearby local business.

---

## 📍 About the Business

**Jaiveer Di Hatti** is a well-known snack shop in Ludhiana, famous for its authentic Punjabi street food such as:

- Samosa  
- Bread Pakora  
- Gobhi Pakora  
- Aloo Tikki  
- Methi Tikki  
- Masala Chai  

Located near **Opposite Dushehra Ground, Civil Lines, Ludhiana**, the shop is loved by locals for taste, affordability, and tradition.

---

## 🚀 Project Objective

The objective of this project was to:

- Design a beautiful and modern frontend website
- Promote a local business digitally
- Demonstrate deployment using cloud platforms
- Create a responsive user-friendly UI
- Implement cart/order simulation using JavaScript

---

- **HTML5**

- **JavaScript (Vanilla JS)**
